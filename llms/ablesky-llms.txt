# AbleSky (能力天空)

> AbleSky, Inc. is an online-education SaaS company incorporated in 2007 in Mountain View,
> California, operating in China through its wholly owned subsidiary 能力天空科技（北京）有限公司.
> Its platform lets a school, training institution or individual instructor stand up a branded
> online school — website, Android and iOS apps, WeChat micro-school and official account — with
> course hosting, live classes, exams, educational-administration workflow and payment collection,
> and it markets roughly 3,000 platform features to tens of thousands of Chinese training
> organisations. AbleSky publishes NO public API: no OpenAPI, AsyncAPI, GraphQL SDL, WSDL, gRPC
> service, MCP server, SDK or developer portal exists on any of its hosts.

## What this file is

## API status — read this before looking for one

There is no AbleSky API to call. Contract discovery was run in full against every host the record
knows, and every probe missed:

- No OpenAPI/Swagger: /openapi.json, /swagger.json, /v2/api-docs, /api-docs, /apis.json all
  return HTTP 404 on www.ablesky.com.
- No developer host: open., developer., docs. and openapi.ablesky.com do not answer.
- api.ablesky.com resolves and answers, but returns a blanket nginx/1.6.0 HTTP 403 on every path
  including "/". It is a locked host, not a documented API.
- No GraphQL (/graphql → 404), no AsyncAPI, no webhook catalogue, no WSDL, no .proto.
- No MCP server, hosted or local.
- No A2A agent card: /.well-known/agent-card.json and /.well-known/agent.json probed on eleven
  AbleSky hosts, all 404 except a 31,546-byte HTML SPA shell on 1.ablesky.com, which was rejected.
- No /.well-known/ documents at all — no security.txt, no openid-configuration, no
  oauth-authorization-server, no api-catalog, no ai-plugin.json.

The nearest thing to an integration surface AbleSky documents in prose is single sign-on: its FAQ
says a school that already runs its own system can embed the AbleSky teaching platform inside it and
share learners between the two, so a student signs in once. No endpoint, parameter or contract for
that is published.

## The one machine-readable document AbleSky does publish

- [OpenSearch 1.1 description](https://www.ablesky.com/s/opensearch.xml): a valid OpenSearch
  description document, correctly auto-discoverable via
  `<link rel="search" type="application/opensearchdescription+xml">` on the homepage. It declares one
  results template, `http://s.ablesky.com/s.do?aft=Course&key={searchTerms}`, of type `text/html` —
  a human-facing course-search page, not a data representation. Contact `service@ablesky.com`,
  attribution "copyright AbleSky, Inc."

## Commercial terms

- Opening an online school is free; an independently branded school (own domain, own Android/iOS
  apps, own WeChat micro-school and official account) is 50 CNY per month.
- Billed monthly, cancellable at any time; annual prepayment is discounted.
- Learner card/WeChat/Alipay payments carry a 0.9% bank fee, which AbleSky states it does not share
  in. No brand fee and no server fee.
- Data export is offered on exit.
- Source: https://www.ablesky.com/product/index/fqa
